# Crop Disease Detection App 🌱

Welcome to **CropGuard AI**, an AI-powered app designed to help farmers, agronomists, and developers identify crop diseases quickly and accurately using images of plants. This project combines machine learning, modern web/mobile interfaces, and easy-to-use tools for anyone interested in agriculture technology.  

---

## 🚀 Features

- 📸 **Image-Based Detection:** Upload or capture a photo of a plant leaf and get instant disease diagnosis.  
- 💡 **AI-Powered:** Uses machine learning (TensorFlow/TFLite) for accurate recognition of multiple crop diseases.  
- 🧩 **Modular Code:** Easy-to-understand TypeScript/JS files ready for extension and experimentation.  
- 🛠 **Developer-Friendly:** Includes sample datasets, detection scripts, routers, dashboards, and testing modules.  
- 🌐 **Cross-Platform:** Can be adapted for mobile or web applications.
  
Visit website:https://cropguardai-kqtrca4s.manus.space/

## 🗂 Project Structure

| File | Purpose |
|------|---------|
| `Home.tsx` | Main home screen UI component |
| `Result.tsx` | Displays disease detection results |
| `Detect.tsx` | Handles the detection process and integrates ML model |
| `App.tsx` | Entry point of the app |
| `SymptomChecklist.tsx` | Helps users describe symptoms for better diagnosis |
| `CompanyDashboard.tsx` | Dashboard for agritech companies or admins |
| `routers.ts` | Routes for app navigation |
| `routers-Company.ts` | Company-specific routes |
| `db.ts` | Database connection logic |
| `Schema.ts` | Database schema definitions |
| `detection.test.ts` | Test cases for detection algorithms |
| `routers-detection.ts` | Routes for detection API endpoints |
| `ensemble.ts` | Ensemble logic for multiple detection models |
| `test-insertid.mjs` | Sample test script |
| `History.tsx` | Tracks past detections |
| `index.css` | App styling |
| `index.html` | App entry HTML |

> The project is modular—feel free to add, modify, or extend any part of it.
